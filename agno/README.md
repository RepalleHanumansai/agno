# AGNO - AI Agent Platform

AGNO is a modular AI Agent Platform that supports:

- **LLM-based agents**: Churn, Fraud, Sentiment, Recommendation, RAG, Chatbot
- **RAG pipeline**: File ingestion, vector store, retrieval
- **Classical ML & NLP**: Churn & fraud prediction, sentiment analysis
- **DSPy programs**: Structured reasoning & decision-making
- **UX-facing chatbot**: Text and voice interaction
